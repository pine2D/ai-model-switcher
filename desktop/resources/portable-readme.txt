PolyAsk Portable

English

Start: App\polyask-desktop.exe

To upgrade:
1. Exit every PolyAsk process.
2. Replace the entire App folder with the one from the new archive. This also replaces the old app.asar.
3. Keep PolyAsk Data. It contains your settings, site sign-ins, and local data.

portable.json and README.txt contain no user data and may be overwritten.

The first time you run this portable version, PolyAsk can copy existing data. Your original settings and sign-ins stay in their current location, so you can still return to the earlier version if needed.

简体中文

启动：App\polyask-desktop.exe

升级：
1. 完全退出所有 PolyAsk 进程。
2. 用新压缩包中的整个 App 文件夹替换旧 App，旧 app.asar 也会一并替换。
3. 保留 PolyAsk Data，其中保存了设置、站点登录状态和本机数据。

portable.json 和 README.txt 不含用户数据，可以直接覆盖。

首次运行此便携版时，PolyAsk 可以复制现有数据。原有设置和登录状态仍保留在原位置，需要时可以继续使用旧版。

繁體中文

啟動：App\polyask-desktop.exe

升級：
1. 完全結束所有 PolyAsk 處理程序。
2. 使用新壓縮檔中的完整 App 資料夾取代舊 App，舊 app.asar 也會一併取代。
3. 保留 PolyAsk Data 資料夾，其中存放設定、網站登入狀態與本機資料。

portable.json 與 README.txt 不含使用者資料，可以直接覆寫。

第一次執行此可攜版時，PolyAsk 可以複製現有資料。原有設定和登入狀態仍保留在原位置，需要時仍可繼續使用舊版。
